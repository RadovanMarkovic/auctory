# Auctory: Luxury Auctions

We are building Auctory, a bilingual Web4 auction platform for luxury watches, jewelry, collectibles, and limited-edition fashion. Use React, Vite, TypeScript, Tailwind CSS, shadcn/ui, and Supabase. The platform uses English ascending auctions, seller approval, simulated post-auction payments, Sepolia ERC-721 product certificates, ownership history, and a LangChain AI assistant.

For this step, only inspect the current project and establish reusable architecture, routes, types, and folders. Do not build all features yet. Preserve working code, avoid duplicate components and tables, and never expose secrets in frontend code. At the end, summarize the proposed structure and any manual setup required.

Create the visual foundation for Auctory. Use a premium, elegant auction-house style with warm ivory backgrounds, charcoal text, restrained gold accents, generous spacing, and high-quality typography. Build reusable Button, Card, Badge, EmptyState, LoadingState, ErrorState, PageHeader, and ConfirmationDialog components.

Create a responsive application shell with header, footer, desktop navigation, mobile navigation, language switcher placeholder, account menu placeholder, and wallet button placeholder. Do not implement authentication or blockchain yet. Do not modify unrelated code.
